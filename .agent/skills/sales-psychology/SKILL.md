# Sales Psychology — A Neurociência de Vender Online

> **Princípio:** O ser humano é irracional de forma previsível. Use isso para ajudá-lo a comprar o que ele já quer.
> ⚠️ **Ética:** Esses princípios ajudam o cliente a tomar BOAS decisões — nunca manipular ou enganar.

---

## 1. NEUROCIÊNCIA DA DECISÃO

### Os 3 Cérebros que Compram

```
PRIMITIVO (Reptiliano) → Decide primeiro
  Responde a: dor/prazer, clareza visual, velocidade
  Como atingir: imagens, contraste, CTA óbvio

EMOCIONAL (Límbico) → Sente
  Responde a: histórias, status, pertencimento, FOMO
  Como atingir: reviews, narrativa, identidade

RACIONAL (Neocórtex) → Justifica depois
  Responde a: specs, preço, comparações
  Como atingir: tabelas, garantias, certificações
```

### Sequência de Decisão Real

```
1. Estímulo visual (0.05s)
2. Emoção subliminar ("quero isso")
3. Atenção consciente (nome, preço)
4. Validação social (reviews)
5. Justificativa racional (specs)
6. Objeção ("mas e se...?")
7. Remoção de risco (garantia)
8. Ação (compra)
```

## 2. OS 7 GATILHOS MENTAIS PRIMÁRIOS

### 1. RECIPROCIDADE
```
Princípio: Quando recebemos algo, sentimos obrigação de retribuir.

✅ Brinde com compra → aumenta AOV
✅ Frete grátis → gera compra de item maior
✅ "Você economizou R$X nessa compra"
✅ Desconto de boas-vindas para novos visitantes

Copy: "Presente exclusivo — [produto bônus] grátis nessa compra"
```

### 2. COMPROMETIMENTO E CONSISTÊNCIA
```
Princípio: Após decidir algo pequeno, mantemos consistência.

✅ "Salvar na lista de desejos" → primeiro passo
✅ Configurador progressivo (cor → memória → capacidade)
✅ Quiz "Qual produto é perfeito para você?"
✅ Seleção de variação antes de ver preço

Copy: "Adicione ao carrinho — guardamos por você"
```

### 3. PROVA SOCIAL
```
Princípio: Em dúvida, seguimos o que a maioria faz.

Hierarquia de credibilidade:
1. Reviews com foto/vídeo de clientes reais
2. Rating + número de avaliações (4.8★ — 1.847 avaliações)
3. "Mais vendido da categoria" badge
4. Número de pedidos ("+50.000 enviados")
5. Selos de premiação

Posicionamento:
- Rating: ao lado do nome do produto
- Reviews: antes dos specs técnicos
- "Mais vendido": badge no card e PDP
```

### 4. AUTORIDADE
```
Princípio: Seguimos especialistas percebidos.

✅ "Apple Authorized Reseller"
✅ Certificações do produto (MIL-SPEC, IP68)
✅ Selos de qualidade (INMETRO, ABNT)
✅ "Como visto na Globo / Folha de SP"
✅ Anos de experiência no mercado

Copy: "Revendedor oficial Apple — garantia de fábrica"
```

### 5. ESCASSEZ (USAR SÓ SE VERDADEIRO)
```
Régua de estoque:
> 10 unidades:  não mostrar
5-10 unidades:  "Poucas unidades"
2-4 unidades:   "Apenas X em estoque"
1 unidade:      "Última unidade!"
0:              "Esgotado — avise-me"

Escassez temporal real:
"Preço promocional até domingo"
"Frete grátis válido até hoje à meia-noite"

⚠️ NUNCA escassez falsa — destrói credibilidade permanentemente.
```

### 6. URGÊNCIA (REAL)
```
✅ "Compre hoje, receba amanhã — pedidos até 14h"
✅ "Promoção termina em [data específica]"
✅ "X pessoas olhando este produto agora" (se real)
✅ "25 vendidos nas últimas 24h" (se real)

❌ Contador fake que reinicia = dark pattern = ilegal
```

### 7. AFINIDADE
```
Princípio: Compramos de quem gostamos e com quem nos identificamos.

✅ Mostrar pessoas como o cliente usando o produto
✅ Tom conversacional e humano (não corporativo)
✅ Valores compartilhados (sustentabilidade, local)
✅ Suporte com nome e foto real do atendente

Copy: "Para quem não abre mão de tecnologia e praticidade"
```

## 3. VIESES COGNITIVOS APLICADOS

### Ancoragem (Anchoring)
```
Primeiro número visto = âncora para comparação.

DE: ~~R$2.499~~ → POR: R$1.899
(A âncora de R$2.499 faz R$1.899 parecer barato)

Produto isca (decoy pricing):
  Básico: R$99  (limitado)
  Pro: R$199    ← TARGET: o que você quer vender
  Elite: R$499  ← âncora superior que valoriza o Pro

Parcelamento:
  Destacar: "12x de R$158" (não o total de R$1.899)
```

### Perda vs. Ganho (Loss Aversion)
```
Princípio: Dor da perda é 2x mais forte que prazer do ganho.

FRACO (ganho):  "Ganhe 20% de desconto"
FORTE (perda):  "Não perca 20% — oferta acaba domingo"

FRACO: "Frete grátis disponível"
FORTE: "Você está prestes a perder o frete grátis — adicione R$X"

Barra de progresso:
"Adicione R$47 para NÃO pagar frete" > "Ganhe frete grátis"
```

### Paradoxo da Escolha (Hick's Law)
```
Mais opções = mais dificuldade = menos conversão.

✅ Máximo 3 planos/opções principais
✅ Destacar uma opção como "Mais Popular" / "Recomendado"
  → Aumenta conversão do item marcado ~30%
✅ Filtros escalonados (não mostrar tudo de uma vez)
✅ Variações: mostrar as mais vendidas primeiro
```

### Enquadramento (Framing)
```
Mesma informação, apresentações diferentes:

PREÇO:
"R$6/dia" = R$180/mês (dia parece menos)

DEVOLUÇÃO:
"100% do dinheiro de volta" > "Reembolso garantido"

GARANTIA:
"2 anos de garantia" > "24 meses de garantia"

REVIEWS:
"4.8 de 5 estrelas" > "96% de aprovação"
(ambos equivalentes — estrelas são mais visuais)

DESCONTO:
Use % quando é número alto em itens caros: "20% OFF de R$1.000"
Use R$ quando é número alto em itens baratos: "R$20 OFF de R$100"
→ Regra: use o número maior.
```

## 4. PROVA SOCIAL AVANÇADA

### Anatomia do Review Perfeito
```
1. ★★★★★ (rating visual)
2. Título com benefício: "Melhor compra do ano"
3. Conteúdo específico (não "ótimo produto")
4. Nome + foto real
5. Data recente
6. Variação comprada (cor/tamanho)
7. "Comprador verificado" badge

Reviews negativos (1-2★): NÃO ESCONDER
→ Presença de críticas aumenta credibilidade total
→ Responder profissionalmente demonstra cuidado
```

### Prova Social em Tempo Real
```
"X pessoas olhando agora" → FOMO + validação
"João de SP comprou há 2 horas" → FOMO + social proof
"847 pessoas compraram depois de ver este produto" → bandwagon
```

## 5. PREÇO PSICOLÓGICO

### Charm Pricing vs. Preço Premium
```
CHARM PRICING (itens de massa):
R$199 > R$200 (1 real a menos = significativamente mais barato na percepção)

PREÇO REDONDO (itens de luxo/premium):
R$2.000 > R$1.998 (preço redondo = qualidade percebida = autoconfiança)
→ Luxury brands: SEMPRE preço redondo

BUNDLING:
"Kit completo: R$299" vs. separados: câmera R$199 + tripé R$129 = R$328
→ Mostrar economia: "Você economizia R$29 (9% off)"
```

---

## 6. PSICOLOGIA DO STATUS

```
Pessoas compram para sinalizar status — para si e para outros.

PRODUTOS PREMIUM (Apple, marcas de luxo):
→ Identidade: "Para quem valoriza o melhor"
→ Pertencimento: "Bem-vindo ao universo [marca]"
→ Imagens: lifestyle aspiracional, não só produto isolado

PRODUTOS DE VALOR (custo-benefício):
→ Inteligência: "A escolha inteligente"
→ Empowerment: "Mesma qualidade, sem pagar pelo logo"
→ Specs: tabelas comparativas detalhadas
```

---

## 7. ANTI-PADRÕES (DARK PATTERNS)

### ❌ NUNCA USAR
```
URGÊNCIA FALSA:
❌ Contador que reinicia ao zerar
❌ "Apenas 2 em estoque" permanente (independente do real)
❌ "50 pessoas olhando" (número inventado)

CONFIRMSHAMING:
❌ "Não, prefiro perder dinheiro" (botão de recusa)
❌ "Não obrigado, não quero economizar"

CUSTOS OCULTOS:
❌ Frete revelado apenas no último passo do checkout

BAIT AND SWITCH:
❌ Anunciar preço X, cobrar Y no checkout
```

> **Regra de Ouro:** Se você precisaria esconder a técnica do cliente para funcionar = dark pattern = não use.
