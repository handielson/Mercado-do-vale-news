# Product Copywriting — Textos que Vendem

> **Missão:** Palavras são vendedores. Cada frase tem uma função. Cada palavra ganha ou perde uma venda.
> **Princípio:** Venda transformação, não produto. O cliente não quer uma furadeira — quer o buraco na parede.

## 1. FUNDAMENTOS (SEMPRE LER)

### O Cérebro que Compra

```
O ser humano compra por EMOÇÃO e justifica por LÓGICA.

Sequência de decisão:
SENSAÇÃO → DESEJO → JUSTIFICATIVA → AÇÃO

Seu copy deve:
1. Criar sensação (imagem mental do benefício)
2. Amplificar desejo (consequências de ter/não ter)
3. Fornecer lógica (specs, preço, garantia)
4. Remover fricção (CTA claro, garantia)
```

### Hierarquia do Copy

```
HEADLINE (80% do peso)     → Faz parar e ler
SUBHEADLINE                → Expande o benefício
BENEFITS (bullets)         → Prova que resolve
PROOF (reviews/selos)      → Remove dúvida
CTA                        → Direciona ação
```

> 🔴 **Se o headline falhar, nada mais importa.** 80% das pessoas lê apenas o título.

### Feature vs. Benefit — A Regra de Ouro

```
FEATURE (o que É):     "Bateria de 5000mAh"
BENEFIT (o que FAZ):   "Bateria para 2 dias de uso intenso"
BENEFIT PROFUNDO:      "Nunca mais dependa de tomada em viagens"

Técnica: "O que isso significa para o cliente?"
Pergunte 3x até chegar no benefício real.

Feature → "Câmera de 108MP"
E daí?   → "Fotos ultra-detalhadas"
E daí?   → "Amplie sem perder qualidade"
E daí?   → "Fotos que parecem de câmera profissional — sem precisar ser fotógrafo"
```

## 2. HEADLINES QUE PARAM O SCROLL

### Fórmulas de Headline Testadas

**Fórmula 1 — Benefício + Especificidade**
```
"[Produto] que [benefício mensurável] em [tempo]"
Ex: "Carregador que vai de 0 a 80% em 30 minutos"
```

**Fórmula 2 — Problema → Solução**
```
"Cansado de [dor]? [Produto] resolve isso"
Ex: "Cansado de celular morrendo no meio do dia? Galaxy A55 tem solução."
```

**Fórmula 3 — Para Quem É**
```
"Para [persona] que [desejo/situação]"
Ex: "Para quem trabalha remoto e precisa de call sem travar"
```

**Fórmula 4 — Número + Benefício**
```
"[N] razões por que o [produto] é o mais vendido do Brasil"
"[N] hours of battery. Zero compromises."
```

**Fórmula 5 — Urgência + Exclusividade**
```
"Só hoje: [produto] com [desconto/brinde] exclusivo"
"Edição limitada: [N] unidades disponíveis"
```

**Fórmula 6 — Comparação ("Melhor que...")**
```
"Performance de R$5.000 — por R$2.199"
"Camera igual ao iPhone — metade do preço"
```

### Headlines por Categoria

```
SMARTPHONE:
✅ "iPhone 13 — O mais vendido por um motivo: simplesmente funciona"
✅ "Samsung A55: câmera que surpreende, bateria que não decepciona"
❌ "iPhone 13 128GB Space Gray"

NOTEBOOK:
✅ "MacBook Air M2 — Leve o suficiente para levar sempre, rápido o suficiente para qualquer coisa"
✅ "Notebook Gamer que não pesa no bolso — nem na mesa"
❌ "Notebook Dell 15.6 polegadas Core i5"

ACESSÓRIO:
✅ "Fone sem fio que dura a semana inteira"
✅ "Case que protege como case, parece que não tem nenhuma"
```

## 3. DESCRIÇÕES DE PRODUTO

### Estrutura Vencedora (PDP)

```
[HEADLINE — Benefício principal]

[PARÁGRAFO ABERTURA — 2-3 linhas que pintam o cenário]
Imagine [situação desejada]. Com [produto], [benefício emocional].

[BULLETS — 4-6 benefícios, não features]
• [Benefício 1]: [Explicação em 1 linha]
• [Benefício 2]: [Explicação em 1 linha]
• [Benefício 3]: [Explicação em 1 linha]

[SPECS TÉCNICAS — Para a mente racional]
Processador: X | RAM: Y | Tela: Z

[GARANTIA / REMOÇÃO DE RISCO]
30 dias para devolver. Sem perguntas.
```

### Linguagem por Público

| Público | Tom | Palavras-chave |
|---------|-----|---------------|
| **Gamer** | Intenso, técnico, direto | "fps", "lag", "framerates", "dominação" |
| **Profissional** | Preciso, eficiente | "produtividade", "desempenho", "fluxo" |
| **Estudante** | Custo-benefício | "faz tudo", "duradouro", "sem travar" |
| **Família** | Seguro, confiável | "fácil de usar", "durável", "intuitivo" |
| **Tech savvy** | Especificações detalhadas | benchmarks, comparações técnicas |

### Palavras que Vendem vs. Palavras Mortas

```
PALAVRAS MORTAS → ALTERNATIVAS VIVAS:
"bom"          → "excepcional / surpreendente"
"rápido"       → "responde em milissegundos"
"bonito"       → "elegante / sofisticado / premium"
"resistente"   → "sobrevive a quedas de 1,5m"
"prático"      → "cabe no bolso da calça"
"econômico"    → "R$X por dia — menos que um café"

VERBOS DE AÇÃO:
Garanta | Descubra | Transforme | Domine | Experimente
Liberte | Conquiste | Maximize | Explore | Alcance
```

## 4. BULLETS QUE CONVENCEM

### Estrutura de Bullet Vencedor

```
❌ Fraco:    "Bateria de longa duração"
✅ Médio:    "Bateria que dura o dia inteiro"
✅✅ Forte:  "🔋 Bateria para 2 dias — Recarregue de manhã e esqueça a tomada"

Fórmula: [Ícone] [Benefício Bold]: [Prova/contexto em 1 linha]
```

### Templates de Bullets

```
PERFORMANCE:
🚀 [Spec] que [resultado]: "[produto] processa [X] sem travar"

PRATICIDADE:
⚡ [Ação fácil]: "Configure em [tempo] — sem manual, sem complicação"

DURABILIDADE:
🛡️ [Proteção]: "Certificação [X] — resistente a [situação real]"

CUSTO-BENEFÍCIO:
💰 [Comparação]: "Performance de [categoria superior] — preço de [categoria inferior]"

EXCLUSIVIDADE:
✨ [Diferencial]: "Único no Brasil com [feature]"
```

## 5. CTAs (CALLS TO ACTION) PERSUASIVOS

### Framework VERB + BENEFIT

```
❌ Genérico:    "Comprar"
✅ Ação:        "Adicionar ao Carrinho"
✅✅ Persuasivo: "Quero Este Produto"
✅✅✅ Poderoso:  "Garantir Meu Desconto de 24%"

Fórmula: [Verbo de posse] + [o que o cliente ganha]
"Pegar o meu" / "Quero Economizar" / "Garantir Agora"
```

### CTAs por Contexto

| Contexto | CTA Fraco | CTA Forte |
|----------|-----------|-----------|
| Produto disponível | "Comprar" | "Adicionar ao Carrinho" |
| Promoção | "Aproveitar" | "Garantir Meu Desconto" |
| Escassez | "Comprar logo" | "Quero — Estoque Esgotando" |
| Produto caro | "Parcelar" | "Parcelar em 12x Sem Juros" |
| Brinde | "Comprar" | "Comprar + Ganhar [Brinde]" |
| Assinatura | "Assinar" | "Começar Grátis por 7 Dias" |

### Microcopy em Torno do CTA

```
Abaixo do botão — Remove ansiedade:
"✓ Envio grátis para SP hoje"
"✓ 30 dias para devolver"
"✓ Pagamento 100% seguro"
"✓ Parcele em até 12x sem juros"

Próximo ao preço — Aumenta urgência:
"Preço válido por tempo limitado"
"Apenas X em estoque"
"Frete grátis só hoje"
```

## 6. COPY PARA SITUAÇÕES ESPECÍFICAS

### Produto Reacondicionado / Usado

```
Nunca use: "usado", "velho", "segunda mão"
Use:        "recondicionado", "seminovo", "certificado"

Headline: "iPhone 12 Recondicionado Certificado — Como Novo, Preço Real"
Benefício: "Testado em 50 pontos de qualidade"
Garantia:  "Mesma garantia do produto novo"
```

### Produto Importado

```
Benefício diferente: "Versão internacional — disponível antes do Brasil"
Confiança:           "Importado com nota fiscal e garantia"
Remoção de medo:    "Sem taxa surpresa — preço final inclui todos os impostos"
```

### Bundle / Combo

```
❌ "Kit iPhone + Capa + Película"
✅ "Kit Proteção Completa — iPhone protegido do dia 1"

Regra: Nomeie o bundle pela transformação, não pelos itens.
```

### Produto Sem Reviews (Novo)

```
Substitutos de prova social:
"Da marca líder em [categoria]"
"Tecnologia usada em [referência conhecida]"
"[N] anos de garantia — confiamos tanto que garantimos"
"Seja dos primeiros a ter"
```

## 7. COPY PARA EMAILS DE RECUPERAÇÃO

### Email 1 — Abandono de Carrinho (1h depois)

```
ASSUNTO: "Você esqueceu algo 👀"
ou: "[Nome], seu [produto] está esperando"

CORPO:
[Nome], notamos que você deixou o [produto] no carrinho.

[Imagem do produto]

➡️ [Nome do produto] - R$[preço]

Ainda disponível — mas o estoque é limitado.

[BOTÃO: Finalizar Compra]

Alguma dúvida? Responda este email.
```

### Email 2 — Abandono (24h depois)

```
ASSUNTO: "Última chance — [Produto] pode esgotar"

Adicionar: urgência real de estoque
Adicionar: 1 review de cliente
Adicionar: garantia de devolução
```

### Email 3 — Abandono (72h depois)

```
ASSUNTO: "Presente especial para você finalizar sua compra"

Adicionar: desconto ou frete grátis (se a margem permitir)
Adicionar: depoimento detalhado
Adicionar: "Se mudou de ideia, tudo bem — mas aqui está por se quiser"
```

## 8. ANTI-PADRÕES DE COPY

### ❌ Nunca Escreva

```
"Qualidade incomparável" → Vazio, todo mundo fala
"O melhor do mercado"   → Sem prova, sem credibilidade
"Preço imperdível"      → Clichê morto
"Aproveite!"            → Fraco, sem especificidade
"Produto incrível"      → Adjetivo sem substância
"Atendimento nota 10"   → Inócuo, esperado

Regra: Se QUALQUER concorrente pode usar a mesma frase → descarte.
```

### ✅ Princípio da Especificidade

```
❌ "Entrega rápida"
✅ "Entrega em até 2 dias úteis para SP"

❌ "Ótimo custo-benefício"
✅ "R$1.899 — o mais barato do Brasil para essa spec"

❌ "Alta qualidade"
✅ "Aprovado em 47 testes de qualidade antes de chegar até você"

Especificidade = Credibilidade
```
