# v1.2.655-meta-payjoy-prints

Data: 19/10/2026. Status: preparada para publicacao validada. Branch: main.
Tag: v1.2.655-meta-payjoy-prints.
Release: /var/www/mdv-site/releases/20261019-171500-v12655-meta-payjoy.

Corrige a interrupcao apos o cliente enviar o print da aprovacao PayJoy no Instagram/Messenger. A API baixa uma imagem de CDN permitida com limite de tamanho e tempo; o adaptador converte para binario e reutiliza o leitor e calculadora PayJoy nativos. Estado PayJoy passa a integrar exclusivamente a memoria duravel Meta, preservando aparelho, revisao e pausa humana. Uma pergunta posterior de entrada usa os campos aprovados, sem novo print e sem usar o preco do aparelho como base.

Arquivos: servicos metaAttendanceReplies/Media; adaptador e publicador n8n Meta PayJoy; publicadores seletivos e plano VPS; validador de execucoes reais; testes focados; tres artefatos de versao. A lista exata consta em public/VERSION.json.

Validacao: 117 regressoes comerciais no candidato exato, 46 testes focados e oito casos nativos do modelo, com prints sinteticos sem clientes. A retomada do worker exige ensaio do webhook real em conversas sinteticas separadas nos dois canais: catalogo, escolha, envio do link, print aprovado, pergunta sobre entrada e pausa humana. Nenhum envio Meta e realizado nesses ensaios.

Publicacao seletiva API antes do workflow; backup criptografado, CAS em entidade/historico, verificacao apos restart e retomada sem alterar o cursor de ativacao. O site publica a versao. Sem migration ou reexecucao de mensagens reais. Alteracoes preexistentes preservadas.
