## O que entrou

- Nova pagina administrativa `/admin/whatsapp/novo-bot`.
- Consulta de status por telefone/JID.
- Reset administrativo de conversa, sem comando pelo cliente.
- Bloqueio e desbloqueio de fluxo por cliente.
- API VPS para controle do novo bot em `/n8n-bot/client-control`.
- Script de patch do workflow n8n para respeitar bloqueio, consumir reset e usar sessao de memoria versionada.

## Observacoes

- A memoria historica antiga nao e apagada fisicamente; apos reset administrativo, o workflow passa a usar uma chave de sessao nova para o cliente.
- O estado de pos-lista do workflow e limpo quando o reset pendente e consumido.
- O bloqueio de fluxo e administrativo e nao depende de frase enviada pelo cliente.
