## Alteracoes

- o recibo usa configuracoes de documento obtidas por uma rota autenticada do cliente;
- a janela de impressao e aberta no clique, evitando bloqueio de pop-up depois das consultas assincronas;
- cada venda PDV exibe a acao `Termo de Garantia`;
- termos ja salvos sao reutilizados e vendas antigas podem regenerar o termo pelo modelo configurado;
- a API verifica que a venda pertence ao cliente autenticado antes de entregar documentos;
- a URL `/perfil` continua compartilhada, enquanto identidade e dados permanecem individualizados pelo token da sessao.
