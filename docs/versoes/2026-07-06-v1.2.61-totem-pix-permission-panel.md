# v1.2.61-totem-pix-permission-panel

Data: 2026-07-06

Release VPS: `/var/www/mdv-site/releases/20260706-180908-totem-pix-permission-panel`

## Resumo

Adiciona painel operacional para liberar notificacoes, bateria sem restricao e permissoes do app no Totem Pix.

## Ajustes

- Android atualizado para `versionName 1.21` / `versionCode 121`.
- Manifesto Android declara `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`.
- Ponte Android expõe status e abertura de:
  - notificacoes do app;
  - bateria sem restricao;
  - detalhes/permissoes do aplicativo.
- Painel do Totem exibe status de `Notificacoes` e `Bateria sem restricao`.
- Painel do Totem ganhou botoes:
  - `Liberar notificacoes`;
  - `Liberar bateria`;
  - `Permissoes do app`.
- Display visual passa a mostrar `V1.21`.

## Observacao

Algumas permissoes usadas pelo Totem nao aparecem na tela comum de permissoes do Android porque sao concedidas automaticamente pelo sistema, como `WAKE_LOCK`, `FOREGROUND_SERVICE` e `REORDER_TASKS`. A permissao de notificacao so aparece como permissao runtime no Android 13+. Por isso esta release coloca atalhos explicitos no painel do Totem.
