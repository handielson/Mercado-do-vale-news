# v1.2.133 — Formatação de descrição para a Shopee

Data: 31/07/2026

## Alterações

- Converte automaticamente HTML do cadastro em texto compatível com a descrição do anúncio na Shopee.
- Preserva a organização visual por títulos, parágrafos, quebras de linha e listas com marcadores.
- Normaliza descrições carregadas do produto, aplicadas por templates e digitadas ou coladas manualmente.
- Garante a mesma limpeza tanto na criação quanto na atualização de anúncios.

## Validação

- Testes de descrição padrão da Shopee aprovados.
- Teste do mecanismo de templates com descrição HTML aprovado.
- Build de produção aprovado.
