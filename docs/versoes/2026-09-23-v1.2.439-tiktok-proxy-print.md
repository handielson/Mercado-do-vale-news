## Correção

- O painel TikTok usa caminhos `/tiktok-shop/...` aceitos pelo proxy autenticado, em vez de enviar `/api/...` como parâmetro de proxy.
- A API oferece aliases protegidos para consulta/sincronização da fila e expedição, preservando as rotas `/api/...` usadas diretamente pelo agente Lenovo.
- Nenhuma etapa fiscal é reexecutada automaticamente para pedidos com fila existente; o estado `intervention` continua bloqueando reenvio até conferência.
