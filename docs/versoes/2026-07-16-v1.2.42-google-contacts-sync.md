## Alteracoes

- API central cria ou atualiza contatos sem duplicar o mesmo telefone.
- Telefones brasileiros com e sem nono digito sao tratados como o mesmo contato.
- Criacao, edicao e cadastro publico de clientes sincronizam a agenda Google.
- Workflow n8n usa a API central, sem depender de uma segunda credencial Google.
- Nome valido do perfil WhatsApp e salvo sem interromper a pergunta original do cliente.
- Bot so afirma que salvou quando a People API confirma sucesso; falhas deixam de alimentar o cache.
- OAuth foi renovado diretamente na VPS por tunel temporario, sem exportar segredos.
