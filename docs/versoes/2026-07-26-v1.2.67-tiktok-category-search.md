## Entrega

- Consulta a arvore oficial completa de categorias TikTok Shop para a loja BR.
- Faz a pesquisa aproximada no servidor local, evitando o erro do TikTok para termos nao literais.
- Ordena sugestoes por correspondencia exata, frase e palavras relevantes.
- Mantem a regra segura: somente uma correspondencia exata e confirmada automaticamente.
- Salva a categoria escolhida para que os proximos produtos da mesma categoria local sejam automaticos.
- Evita quebra do modal quando uma resposta externa vier sem a lista de categorias.
- Converte erros de negocio do TikTok retornados em HTTP 200 para HTTP 502 na nossa API.
