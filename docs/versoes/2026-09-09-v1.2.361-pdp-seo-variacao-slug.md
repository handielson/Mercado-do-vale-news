# v1.2.361 — resolução de slug estendido de variação no SEO / OpenGraph

- Data: 2026-09-09
- Branch: `main`
- Status: pronto para publicação
- Release VPS: `pendente`
- Tag: `v1.2.361-pdp-seo-variacao-slug`

## Correção

- A função `loadSeoProductBySlug` no `vps_server.cjs` e `vps_server.js` passou a aceitar tanto o `variantTarget` quanto o `disambiguatedTarget` gerados por `getPublicProductDisambiguatedRouteTargetVps(product)`.
- Links de produtos com sufixo de variação selecionada no frontend (ex: `-preto-8gb-512gb`) agora são resolvidos com sucesso e retornam status HTTP 200 com as metatags OpenGraph (`og:image`, `og:title`, `og:description`).
- Ao compartilhar esses links no WhatsApp, o card de prévia com imagem do produto e título é montado normalmente pelo crawler.

## Causa

- O frontend gera URLs com sufixo desambiguado para identificar a variação escolhida pelo cliente (cor/memória).
- No backend, a busca por prefixo só ativava o sufixo desambiguado caso houvesse colisão exata de base entre os candidatos retornados. Quando as bases diferiam, o servidor comparava apenas o slug base contra o slug estendido, falhava no match e retornava HTTP 410 sem tags `og:image`.
