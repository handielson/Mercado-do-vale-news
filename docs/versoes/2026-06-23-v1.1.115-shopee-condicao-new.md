## Resumo

Corrige o envio do atributo `100413` (`Condicao`) no `add_item` da Shopee para usar o nome original `New` em vez do texto localizado `Novo`.

## Causa

O item publicado estava com os demais atributos corretos, mas a Shopee gravou `Condicao` como valor customizado:

```json
{ "attribute_id": 100413, "value_id": 0, "original_value_name": "Novo" }
```

Isso fazia o Seller Center mostrar o texto no campo, mas sem deixar a opcao do dropdown realmente selecionada.

## Mudancas

- `Novo`/`New` agora e normalizado para `original_value_name: "New"` no payload de `add_item`.
- O bloqueio global de `100413` no `add_item` foi removido.
- O fluxo de `update_item` continua removendo `100413` do `attribute_list`, preservando a regra anterior para edicao de item existente.
- A protecao estatica foi ajustada para impedir regressao desse comportamento.
