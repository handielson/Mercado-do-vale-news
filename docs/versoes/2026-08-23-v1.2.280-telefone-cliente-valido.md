## Resumo

Impede que o PDV, o cadastro administrativo ou a API gravem telefone brasileiro com quantidade invalida de digitos e evita repassar numero malformado para a Evolution API.

## Mudancas

- aceita telefone brasileiro com DDD, com ou sem o codigo de pais `55`;
- normaliza novos telefones de clientes para DDD + numero antes da gravacao;
- bloqueia telefone invalido no cadastro rapido do PDV, formulario administrativo, perfil e service;
- aplica a validacao obrigatoria na API para criacao e atualizacao de clientes;
- diferencia telefone ausente de telefone invalido nos logs da automacao WhatsApp;
- preserva a entrada invalida na tela para correcao, sem truncar silenciosamente um digito;
- inclui regressao comportamental para o numero valido e para o caso de 12 digitos locais.
