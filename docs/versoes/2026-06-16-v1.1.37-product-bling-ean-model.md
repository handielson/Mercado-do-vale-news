## Resumo

Complementa a correcao do cadastro de produtos/unidades vinculados ao Bling. A API VPS ja retornava EAN e `model_id`, mas o formulario lia apenas `eans` e `model`, deixando os campos visiveis vazios.

## Alteracoes

- `components/products/ProductForm.tsx`
  - Normaliza EAN local vindo de `eans`, `ean` e `alternative_eans`.
  - Resolve o nome do modelo via `modelService.getById(model_id)` quando a linha local nao traz `model`.
  - Mantem o preenchimento de `model_id` para o payload e passa a preencher tambem o campo visual `model`.
- `tmp-tests/product-form-bling-model-ean-autofill-static.test.mjs`
  - Cobre o formato real retornado por `/products?bling_id=...`.
- `public/VERSION.json`, `VERSAO_ATUAL.md`
  - Atualizam a versao publicada.
