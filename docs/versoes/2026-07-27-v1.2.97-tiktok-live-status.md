# v1.2.97 - Status TikTok atualizado automaticamente

Data: 27/07/2026

## Alteracoes

- Anuncios com status `PENDING` sao consultados automaticamente enquanto aparecem na pagina de Produtos.
- Quando o TikTok aprova o anuncio, o card muda para publicado sem precisar abrir o modal.
- Os estados `ACTIVE` e `ACTIVATE` sao tratados como anuncio ativo.
- Enquanto o vinculo e verificado, o modal mostra `Verificando anuncio...`.
- Quando existe `tiktok_product_id`, o botao muda para `Anuncio ja vinculado` e nao permite outro rascunho.

## Caso validado

- SKU `CSRN11PVL`, que so atualizava para publicado depois de abrir o modal.
