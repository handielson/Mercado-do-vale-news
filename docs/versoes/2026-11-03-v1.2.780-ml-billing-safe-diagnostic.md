## Mercado Livre

Depois que a consulta de faturamento em lote passou a retornar HTTP 502 sem diagnóstico, a API agora classifica erros sem devolver mensagens ou respostas externas. O diagnóstico allowlisted diferencia falha de transporte, JSON inválido, resposta de faturamento inválida, erro interno e status/código HTTP do upstream quando disponíveis.

O ERP aceita apenas essas classes fixas e continua sem gravar dados em caso de falha. Uma captura concluída continua restrita à prévia local; nenhuma venda, conta a receber ou movimentação de estoque é criada.
