# v1.2.77-status-timeout-aceito

Data: 2026-07-07

## Resumo

- A Evolution registra `Sending message to status@broadcast`, mas o HTTP de `sendStatus` pode ficar aberto sem resposta.
- Quando a chamada interna passa do timeout de confirmacao, o sistema marca como `sent` com debug, nao como `failed`.
- O timeout padrao de confirmacao do Status foi reduzido para 30s para nao bloquear a fila.
- O debug preserva quantidade de contatos, limite de audiencia, tempo e endpoint usado.

## Validacao

- Logs da Evolution mostraram `Sending message to status@broadcast`.

- `node tmp-tests\whatsapp-status-campaign-vps-static.test.mjs`
- `node --check vps_server.js`
- `node --check vps_server.cjs`
- `npm run build`
