# v1.2.728-erp-ml-price-capability

Data: 01/11/2026. Status: API publicada; manifesto do site pendente. Branch: `main`. Tag: `v1.2.728-erp-ml-price-capability`.

## O que mudou

- A capability `listing_price_write_v1` passa a refletir o suporte implementado para atualização do preço padrão via `PUT /items` somente com preço.
- O gate de preço segue independente e exige `MDV_ERP_PRICE_WRITE_ENABLED=1` e chave ERP dedicada válida.
- O deploy desta release mantém publicação, preço e estoque desligados.

## Proteções mantidas

O serviço recusa preço automatizado, promoções, preço por quantidade, canais incompatíveis e atualizações cuja releitura não confirme o valor salvo. Nenhuma escrita externa foi feita nesta validação.

## Validações locais

- Suíte Mercado Livre: 104 testes aprovados e contrato estático aprovado.
- Build de produção aprovado.

## Publicação

API publicada seletivamente. `/status` respondeu HTTP 200 com MySQL OK. GET autenticado confirmou `listing_price_write_v1` e gates de estoque, preço e publicação em `false`. O manifesto público do site permanece pendente.
