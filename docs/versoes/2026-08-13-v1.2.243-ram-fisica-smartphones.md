## Alterações

- Produtos exibem e filtram somente a memória RAM física, sem somar expansão ou RAM virtual.
- Valores compostos, como `24GB (8+16)`, são apresentados como `8GB` de RAM física.
- O cadastro de smartphones por foto orienta a IA a extrair somente a RAM física.
- Importações e atualizações de produtos normalizam o campo principal de RAM antes de salvar, preservando o campo separado de RAM virtual.
