## Entrega

- Cria conexoes Shopee adicionais com nome de identificacao e estado de autorizacao.
- Mantem os tokens e o `shop_id` de cada conexao em tabela dedicada no MySQL.
- Direciona o OAuth da loja escolhida para a conexao correta e renova o token nesse mesmo registro.
- Mantem a integracao principal existente como padrao e nao exibe segredos pela API ou painel.

## Limite desta etapa

Nenhum produto foi enviado, alterado ou excluido. O vinculo de produtos para uma segunda loja sera uma entrega posterior, com a loja de destino selecionada de forma explicita.
