## Alteracoes

- Caixa admin passa a montar os cards e o wizard de fechamento com um resumo seguro quando a API retorna sessao aberta sem resumo.
- Hook do caixa tenta buscar o resumo detalhado por sessao antes de cair no fallback local.
- Resumo vazio usa `opening_amount_cents` como dinheiro esperado inicial, evitando `R$ 0,00` indevido no fechamento.
- API do caixa soma o valor de abertura quando uma sessao antiga nao possui movimento `opening_float`.
- Teste estatico protege o fluxo de resumo/fechamento contra regressao.
