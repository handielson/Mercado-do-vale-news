Data: 2026-07-06

Release VPS: `/var/www/mdv-site/releases/20260706-192822-totem-pix-notificacao-whatsapp`

## Resumo

Corrige notificacao do Totem Pix apos pagamento aprovado e impede sucesso falso no envio de comprovante via WhatsApp.

## Ajustes

- Android atualizado para `versionName 1.22` / `versionCode 122`.
- Display visual passa a mostrar `V1.22`.
- Monitor nativo do Totem Pix passa a acordar/notificar somente para Pix `pending`.
- Ao receber Pix aprovado ou sem Pix ativo, o Android cancela a notificacao `Pix aguardando no Totem`.
- Notificacao de Pix ativo fica cancelavel e nao e reenviada em sequencia para o mesmo Pix.
- Servidor valida o retorno da Evolution/API antes de marcar comprovante WhatsApp como enviado.
- Se a API do WhatsApp falhar, o Totem mostra erro em vez de `Comprovante enviado`.
