# v1.1.47 - PDV Serialized Inventory Rebuild

Data: 2026-06-16

Status: published

Release VPS: `/var/www/mdv-site/releases/20260616-170149-v1147-pdv-serialized-inventory-rebuild`

## Resumo

Reconstrui o fluxo de itens serializados no PDV para separar produto/SKU de unidade fisica. A busca por nome/SKU agora mostra um card agrupado por produto com seletor das unidades disponiveis, enquanto a busca por IMEI/Serial adiciona diretamente a unidade exata ao carrinho.

## Mudancas

- Cria `services/pdvSerializedInventory.ts` para montar cards PDV e labels de unidades.
- Agrupa produtos serializados em um unico card no modo `Nome / SKU`.
- Lista unidades disponiveis dentro do card, sem concatenar varios seriais em uma linha.
- Remove a dependencia de identificadores legados em `product.specs` para decidir venda serializada.
- Mantem o scan de `IMEI / Serial` direto para carrinho com `unitData` da unidade encontrada.
- Bloqueia duplicidade do mesmo `unitId` no carrinho.
- Adiciona `/pdv/product-search` na API VPS para retornar produtos hidratados com unidades disponiveis.
- Adiciona auditoria read-only para encontrar dados legados ou inconsistentes.
