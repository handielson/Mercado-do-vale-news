# n8n e Task Runner 2.33.7

## Problema

Algumas mensagens eram classificadas corretamente pela IA, mas a execução terminava antes da busca de produtos e do envio pelo WhatsApp. O processo JavaScript do Task Runner caía com `Cannot assign to read only property 'prependListener' of object '#<Socket>'`.

## Correção

- atualizar juntos `n8n_n8n` e `n8n_n8n-runner` para a versão oficial 2.33.7;
- substituir as tags mutáveis `latest` por versões fixas `2.33.7` no Docker Swarm;
- manter a ordem segura: parar runner e n8n, atualizar as duas imagens, iniciar n8n e depois runner;
- validar versão, réplicas e ausência da assinatura conhecida do crash nos logs novos.
