## Resumo

Os defaults universais da Shopee agora tambem sao aplicados quando a tela de Modelos carrega os atributos da categoria na aba JSON / IA. Isso corrige o caso em que os defaults apareciam salvos em Templates, mas os campos do modelo continuavam vazios.

## Alteracoes

- `components/settings/ModelModal.tsx`: carrega `shopeeTemplateService.list()` ao buscar atributos da categoria e mescla `universal_defaults` antes dos valores ja salvos no modelo.
- `components/settings/ModelModal.tsx`: renderiza placeholders dos defaults universais e usa dimensoes do modelo como contexto para `{package_dimensions}`.
- `components/settings/ModelModal.tsx`: alinha defaults com as opcoes retornadas pela Shopee para selects aparecerem selecionados.
- `tmp-tests/shopee-universal-attribute-defaults-static.test.mjs`: protege a ponte entre defaults universais e o modal de modelos.
