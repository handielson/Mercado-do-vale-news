## O que entrou
- **IMEI completo (`entry-full-identity-v1`):**
  - Cada linha da Lista de entrada ganha uma segunda linha com **Serial, IMEI 1 e IMEI 2 completos**, em fonte de largura fixa e fácil de selecionar.
  - Vale para Manual, Bipar, atalho e Foto (na Foto, os dados vêm do pré-cadastro).
  - A mensagem "Cadastrado com sucesso!" mostra os mesmos dados de cada aparelho.
  - O rótulo curto ("IMEI …2227") continua igual.
- **SKU uma vez só (`entry-sku-once-v1`):**
  - O nome dos produtos já termina com o SKU ("Poco X8 5G - Preto / 8GB / 256GB - POCO0001-01"). Agora o SKU só é acrescentado quando não está no nome.
  - Vale para a linha do atalho, o cabeçalho do Bipar ("Alterar configuração") e a busca por código/SKU.
  - Linhas que já estavam salvas no rascunho do navegador mantêm o rótulo antigo até sair da lista.
