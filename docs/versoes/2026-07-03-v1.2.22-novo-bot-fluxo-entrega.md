## O que entrou

- Painel `/admin/whatsapp/novo-bot` exibe nome do contato quando o n8n envia `contactName`.
- Lista de conversas ganhou seta expansivel com previa compacta do historico.
- API VPS persiste e retorna `contact_name` em conversas e mensagens do Novo Bot.
- Fluxo n8n de vendas continua para entrega ou retirada depois de separar item e quantidade.
- Entrega pede CEP, consulta endereco por HTTP Request do n8n e depois pede numero/complemento.
- Retirada envia localizacao da loja, pergunta horario e valida horario dinamico da empresa.
- Fluxo segue para pagamento com Pix, cartao ou dinheiro.
- Lista de celulares passa a ser enviada em blocos de 5 produtos.
- Agente de entrada reconhece perguntas aleatorias sobre horario da loja.

## Observacoes

- A busca de CEP no fluxo ativo foi migrada para um node HTTP Request real do n8n, evitando falha silenciosa de `fetch` dentro de Code node.
- A versao ativa do workflow n8n foi alinhada entre `versionId` e `activeVersionId` para impedir execucao de historico antigo.
- Scripts em `tmp-tests/n8n-*.cjs` registram os hotfixes aplicados e validacoes read-only usadas no fluxo.
