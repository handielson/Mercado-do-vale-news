## O Que Entrou

- Card "Entregadores" no dashboard admin em Operacoes Diarias.
- Navegacao do atalho para `/admin/customers?delivery=1`.
- Inicializacao da lista de clientes com filtro `is_delivery_worker: true` quando `delivery=1` esta na URL.
- Filtro avancado "Tipo" para alternar entre Todos, Clientes e Entregadores.
- Indicador visual "Mostrando apenas entregadores" quando o filtro esta ativo.
