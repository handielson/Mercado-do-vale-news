## Resumo

Preenche automaticamente `Tamanho do Pacote` no template Shopee de fonte de alimentacao.

## Causa

A versao anterior liberou o envio do atributo `101029`, mas o template local `power_supply` nao tinha um default para esse campo. Assim, a Shopee ja recebia os outros atributos, mas `Tamanho do Pacote` continuava vazio no Seller Center.

## Mudanca

- Adiciona `101029: '1 Piece'` nos defaults do template `power_supply`.
- Atualiza o teste de template para exigir esse valor mesmo quando o produto tem dimensoes logisticas, evitando voltar a mandar dimensoes fisicas no atributo errado.
