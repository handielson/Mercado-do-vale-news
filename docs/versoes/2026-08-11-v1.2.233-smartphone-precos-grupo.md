# v1.2.233 — Preços agrupados no cadastro por foto

Data: 11/08/2026

## Entrega

- Identifica aparelhos iguais pela combinação exata de modelo, RAM, armazenamento e cor.
- Exibe a opção `Aplicar aos X aparelhos iguais` quando há mais de um item compatível na fila.
- Confirma compra, varejo, revenda e atacado uma única vez para todo o grupo.
- Mantém foto, IMEI, número de série e finalização separados por aparelho.
- Permite desmarcar o agrupamento e confirmar somente o aparelho selecionado.
- Atualiza o grupo dentro de uma transação, com bloqueio das linhas, para evitar confirmação parcial.
- Ignora aparelhos já concluídos ou cancelados.
