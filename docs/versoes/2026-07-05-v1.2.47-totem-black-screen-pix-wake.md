# v1.2.47-totem-black-screen-pix-wake

Data: 2026-07-05

## Resumo

Corrige tela preta do Totem Pix para continuar recebendo Pix apos voltar das configuracoes.

## Causa raiz

O controle automatico de horario fechado chamava `requestScreenSleep()`. Quando a permissao de administrador estava ativa, isso podia bloquear a tela do aparelho e pausar a WebView, impedindo o polling de perceber um novo Pix.

## Melhorias | implementacoes

- App Android atualizado para `versionName 1.14` e `versionCode 114`.
- Controle automatico de horario nao bloqueia mais a tela com Device Admin.
- Botao manual `Apagar tela` continua usando `requestScreenSleep()`.
- Acao `Voltar para tela inicial do app` reacende a tela antes de retornar para `/display`.
- Pix recebido volta a chamar `setDisplayAwake(true)` pelo fluxo `showPix`.
