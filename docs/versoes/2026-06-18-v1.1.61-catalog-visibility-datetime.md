## Resumo

Publicacao para separar produto ativo para venda de produto visivel no site e corrigir erro de data ao salvar campos personalizados via VPS.

## O Que Mudou

- Adicionada flag `hide_from_catalog` nos tipos e persistencia de produto.
- Produtos ocultos do catalogo continuam ativos para PDV, estoque e venda interna.
- Catalogo publico, pagina direta do produto, mensagem de categoria e PDF excluem produtos ocultos.
- Card de produto no admin recebeu botao de olho/olho riscado para alternar a visibilidade no site.
- Card de produto no admin mostra selo `Oculto no site`.
- VPS cria a coluna `products.hide_from_catalog` quando faltar.
- VPS expoe `PATCH /products/:id/catalog-visibility` para alterar somente a visibilidade do site.
- `table-data` da VPS converte timestamp ISO UTC para formato MySQL antes de `INSERT`, `bulk INSERT` e `PATCH`.
