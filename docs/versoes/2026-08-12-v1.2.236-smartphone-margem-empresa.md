# v1.2.236-smartphone-margem-empresa

Data: 2026-08-12

## Alterações

- A interface envia explicitamente a empresa atual ao salvar a margem de smartphones por marca.
- A API usa a empresa vinculada à própria marca como alternativa segura quando o identificador não vier na requisição.
- A alteração das margens não recalcula nem modifica retroativamente os preços dos celulares já cadastrados.

## Validações

- Testes estáticos e funcionais do cadastro de smartphones por foto.
- Verificação de sintaxe da API.
- Build de produção da interface.
