# v1.2.540-ml-atributos

Data: 2026-10-02. Status: pronta para publicação. Branch: main.
Tag: v1.2.540-ml-atributos.
Release: /var/www/mdv-site/releases/20261002-184215-ml-atributos.

Problema: atributos secundários ficavam vazios; a ficha oficial dependia de consulta manual e todos os campos usavam texto livre.

Resultado: categoria definida carrega toda a ficha, incluindo opcionais e campos internos identificados. Resposta atrasada não troca a ficha ativa. Valores existentes são preservados, com aviso para atributos que não pertencem à nova categoria. Booleanos usam opções oficiais; valores numéricos com unidade apresentam seletor; “Não se aplica” é escolha explícita e serializa value_id -1 com value_name null. A API bloqueia booleanos e unidades inválidos, campos internos e N/A em atributos obrigatórios/de variação.

Dados canônicos: categoria e definições da API oficial; GTIN/condição no rascunho; SKU e medidas no cadastro. A pesquisa local recebe a ficha editável e deve documentar lacunas, sem inventar especificações. Na consulta real de MLB5095 foram retornados 73 atributos, sendo 36 editáveis e 37 read_only.

Validações: 28 testes de publicação/preparação; UI com rede externa bloqueada, atributos opcionais, N/A, unidades, resposta atrasada de outra categoria e publicação simulada da família; suíte Mercado Livre; checks de sintaxe; build com trava Supabase.

Escopo: pages/admin/settings/MercadoLivrePreparationPage.tsx, scripts/mercado-livre-local-codex.cjs, services/mercadoLivrePublication.cjs, tmp-tests/mercado-livre-publication-ui.test.mjs, tmp-tests/mercado-livre-publication.test.cjs, public/VERSION.json, VERSAO_ATUAL.md e este registro. Deploy de site e API. Sem alteração de estoque, preço ou atributos dos anúncios existentes nesta entrega.
