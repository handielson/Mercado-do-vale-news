# v1.2.63-whatsapp-comprovante-evolution-env

Data: 2026-07-06

Release VPS: `/var/www/mdv-site/releases/20260706-194414-whatsapp-comprovante-evolution-env`

## Resumo

Corrige o envio do comprovante WhatsApp do Totem Pix para usar as credenciais Evolution atuais da VPS.

## Causa

Na VPS, a tabela `whatsapp_settings` nao existe para esse banco. O envio transacional caia no fallback legado `sendAutoresponderEvolutionTextMessage`, que usa a instancia antiga `mercado_do_vale` e uma chave hardcoded antiga. A Evolution recusava o envio com HTTP 401.

## Ajustes

- `sendDeliveryWhatsappText` agora usa `getN8nBotEvolutionSettings()`.
- O envio transacional usa `EVOLUTION_API_KEY` e a instancia atual `botmercadodovale`.
- O fallback legado do autoresponder nao e mais usado por comprovantes/automacoes transacionais.
- Teste de contrato impede voltar a usar a instancia/chave legada nesse envio.

## Validacoes

- `node tmp-tests\pdv-totem-backend-contract-static.test.mjs`
- `node --check server.js`
- `node --check vps_server.js`
- `node --check vps_server.cjs`
- Checagem remota da Evolution: `botmercadodovale` autenticou com HTTP 200 e `state: open`.
- `npm.cmd run build`
