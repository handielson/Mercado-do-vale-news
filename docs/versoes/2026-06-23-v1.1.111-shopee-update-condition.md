## Resumo

Corrige a sincronizacao Shopee quando o fluxo reaproveita um produto existente e chama `update_item`.

## Causa

O log de publicacao mostrou falha em `update_item:existing_item`, nao em `add_item`:

```text
classification.attribute_value_not_map
Attribute value is not linked to Condition. Please select a valid value.
```

O payload de atualizacao enviava `condition: "NEW"` como campo nativo e tambem enviava o atributo `100413` (`Condition`) dentro de `attribute_list`. Para item existente, essa duplicidade pode fazer a Shopee rejeitar o enum de Condition mesmo com `value_id: 2497`.

## Mudancas

- Mantem `condition: "NEW"` no payload nativo da Shopee.
- Remove o atributo `100413` de `attribute_list` somente no caminho `update_item:existing_item`.
- Preserva o comportamento atual de `add_item`, onde o atributo `100413` continua sendo enviado quando a categoria o retorna.
- Adiciona teste estatico para impedir regressao desse caminho especifico de update.
