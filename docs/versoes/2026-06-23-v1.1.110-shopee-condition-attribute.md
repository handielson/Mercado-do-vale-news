## Resumo

Publicacao Shopee passa a enviar o campo "Condicao" tambem como atributo `100413` no `attribute_list` quando a categoria retorna esse atributo no `get_attribute_tree`.

## Mudancas

- Mantem `condition: "NEW"` no topo do payload `add_item`.
- Remove o bloqueio que omitisse globalmente o atributo `100413` do `attribute_list`.
- Preenche automaticamente `100413` como `Novo` para que o payload gere o `value_id` oficial `2497` / `New`.
- Preserva o retry que remove atributos opcionais customizados quando a Shopee rejeita o anuncio com `classification.attribute`.
