# v1.2.81-totem-brilho-maximo

Data: 2026-07-07

Release VPS: `/var/www/mdv-site/releases/20260707-193000-totem-brilho-maximo`

## Resumo

Corrige o escurecimento da tela no Totem Pix dedicado, mantendo brilho maximo enquanto a tela esta ativa.

## Causa

O app Android mantinha a tela ligada com `FLAG_KEEP_SCREEN_ON`, mas no modo acordado deixava `screenBrightness` como `BRIGHTNESS_OVERRIDE_NONE`. Assim o Android ainda podia aplicar a politica normal de brilho/adaptive dim, mesmo com o Totem em uso.

## Ajustes

- `setDisplayAwake(true)` agora usa `WindowManager.LayoutParams.BRIGHTNESS_OVERRIDE_FULL`.
- O botao manual `Apagar tela` continua usando brilho reduzido e bloqueio quando autorizado.
- Android atualizado para `versionName 1.23` / `versionCode 123`.
- Manifesto publico do site passa a apontar `1.23/123` como versao recomendada.
