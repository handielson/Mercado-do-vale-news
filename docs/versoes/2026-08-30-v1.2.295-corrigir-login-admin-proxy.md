## Resumo

Corrige o bloqueio que respondia `403 Admin required` no login administrativo antes que a API pudesse validar as credenciais.

## O que entrou

- O proxy VPS passa a encaminhar as rotas de login, cadastro, troca e recuperação de senha sem exigir uma sessão administrativa prévia.
- Cada rota de autenticação continua responsável por validar credenciais ou o bearer token aplicável.
- A proteção está coberta por teste de regressão para os dois artefatos de servidor (`vps_server.js` e `vps_server.cjs`).
