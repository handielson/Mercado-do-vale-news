# v1.2.70-status-imagem-preview

Data: 2026-07-07

## Correcoes

- Corrige o preview do Status WhatsApp para usar a imagem principal quando ela vem em `image_url`, `thumbnail`, `main_image_url` ou campos equivalentes, alem de `images`.
- Corrige a validacao e o payload do envio para nao ignorar produtos que tem imagem principal fora do array `images`.
- Adiciona barra de progresso online por campanha para envios manuais e programados.
- Registra o status `sending` antes da chamada para o bot, permitindo acompanhar o item em andamento.
- Adiciona timeout controlado no envio para o bot, evitando aguardar o 504 do Cloudflare sem retorno visual.
- Adiciona cobertura de teste para produto com `image_url` sem `images`.
