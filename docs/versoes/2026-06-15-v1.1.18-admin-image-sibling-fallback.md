## Resumo

Corrige o fallback de imagens da lista de produtos do admin para SKUs novos que chegam sem `images`, sem galeria propria em `model_color_images`, mas com produtos irmaos do mesmo modelo ja contendo imagens.

## Alteracoes

- `components/products/ProductCard.tsx`
  - adiciona busca por produtos irmaos do mesmo `model_id` quando o produto visivel, a galeria de modelo/cor e o produto completo estao sem imagens;
  - prioriza irmao com mesma cor;
  - usa mesmo slug/nome como criterio secundario;
  - hidrata capa e miniaturas do card com as imagens encontradas.
- `tmp-tests/admin-product-card-compact-image-fallback-static.test.mjs`
  - amplia a guarda estatica para exigir o fallback por produto irmao.
- `public/VERSION.json`, `VERSAO_ATUAL.md`
  - registram a nova versao.

## Validacoes

```powershell
node tmp-tests\admin-product-card-compact-image-fallback-static.test.mjs

```
