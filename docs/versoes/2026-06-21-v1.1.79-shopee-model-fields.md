# 2026-06-21 v1.1.79 — shopee-model-fields

## Resumo

Adiciona a aba **🛒 Shopee** no cadastro de Modelos (`ModelModal`), permitindo configurar os campos necessários para o envio automático em lote de variações para a Shopee.

## Arquivos Alterados

- `components/settings/ModelModal.tsx` — nova aba Shopee com UI completa
- `types/model.ts` — campos Shopee tipados no `template_values`
- `public/VERSION.json` — bump para v1.1.79
- `VERSAO_ATUAL.md` — atualizado

## O que Entrou

- **Tipo `TabType`** estendido com `'shopee'`
- **Estados do componente**:
  - `shopeeAutoPublishEnabled` — trava de envio automático em lote
  - `shopeeCategoryId` / `shopeeCategoryName` — categoria Shopee
  - `shopeeAttributeDefaults` / `shopeeAttributeDefaultsText` — atributos padrão da categoria em JSON
  - `shopeeSimilarSearch` / `shopeeSimilarResults` / `shopeeSimilarLoading` — busca de produto similar
- **Carga ao abrir modelo**: `useEffect` lê os campos `shopee_*` do `template_values`
- **Salvamento**: `buildFinalTemplateValues()` mescla os campos Shopee no `template_values` antes de salvar (sem mudança de esquema — usa o campo JSON existente)
- **Handlers**:
  - `buildFinalTemplateValues()` — mescla campos Shopee antes do save
  - `handleShopeeAttributeDefaultsChange()` — valida o JSON em tempo real
  - `handleSearchShopeeSimilar()` — busca produtos locais já sincronizados via `/api/shopee-actions`
  - `handleCopyCategoryFromSimilar()` — copia a categoria de um produto similar com 1 clique
- **UI da aba Shopee**:
  - Banner informativo laranja
  - Toggle de **Trava de Envio Automático** (salvo como `shopee_auto_publish_enabled`)
  - Seção de **Categoria Shopee**: visualização da categoria atual, campos de ID/Nome manuais e busca de produto similar com lista de resultados
  - Seção de **Atributos Padrão**: textarea JSON com validação e badges de visualização

## Armazenamento

Todos os campos são armazenados em `template_values` (campo JSON já existente na tabela `models`) com prefixo `shopee_`. Nenhuma migração de banco necessária.

## Chaves Armazenadas

| Chave | Tipo | Descrição |
|---|---|---|
| `shopee_auto_publish_enabled` | boolean | Libera envio automático em lote |
| `shopee_category_id` | number | ID da categoria Shopee |
| `shopee_category_name` | string | Nome legível da categoria |
| `shopee_attribute_defaults` | object | Atributos obrigatórios padrão da categoria |
