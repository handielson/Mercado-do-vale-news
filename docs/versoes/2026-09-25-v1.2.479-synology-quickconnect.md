# v1.2.479 — Rota QuickConnect exclusiva para backup

O backup do sistema pode usar `MDV_SYSTEM_BACKUP_SYNOLOGY_URL` separado da URL geral do NAS. A autenticação e a listagem pelo QuickConnect foram testadas da VPS após o túnel anterior retornar erro 1033. As demais integrações Synology permanecem no endereço configurado anteriormente. O backup local somente é removido depois da confirmação do envio.
