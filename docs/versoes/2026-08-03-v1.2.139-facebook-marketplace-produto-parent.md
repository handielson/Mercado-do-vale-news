## Alteracoes

- Adiciona programacao assistida de anuncios do Facebook Marketplace na fase de agendamento do Marketing.
- Preenche produto, preco, descricao e imagens a partir do catalogo existente.
- Permite cadastrar Marketplace e grupos de venda como destinos recorrentes.
- Controla os estados agendado, pronto para publicar e publicado.
- Envia lembrete pelo Telegram quando a programacao vence e abre o formulario oficial do Marketplace para conclusao manual.
- Cria a tabela `facebook_marketplace_schedule` automaticamente no boot da API.
- Corrige o cadastro manual para enviar `is_parent=0` em produtos comuns.
- Protege a API para nunca inserir `NULL` em `products.is_parent`, sem desmarcar pais existentes em upserts que omitam o campo.
- Confirma que o SKU `RN708256D` ja usa o cadastro ativo existente do produto Note 70; nenhuma tentativa parcial recente foi criada.
