# v1.2.729 — diagnóstico de leitura do preço do Mercado Livre

Data: 01/11/2026. Status: API publicada; manifesto do site pendente. Branch: `main`. Tag: `v1.2.729-erp-ml-price-read-diagnostic`. Commit: `68719bd0`.

Quando a consulta remota de preço falha, a API do Mercado do Vale informa etapa (`item`, `prices`, `sale_price` ou `price_automation`), status HTTP e código de erro filtrado. O bridge do ERP encaminha somente esses campos allowlisted. Corpos brutos, tokens e dados do anúncio não são devolvidos. Esse diagnóstico permitirá identificar a chamada que causa os HTTP 502 observados sem repetir as quatro chamadas de cada anúncio às cegas.

As rotas de leitura continuam autenticadas. Gates de publicação, atualização de preço e estoque seguem desligados; nenhuma escrita foi enviada ao Mercado Livre e nenhum saldo do Mercado do Vale foi alterado.

Validações locais: `npm.cmd run test:mercado-livre` (106 aprovados e contrato estático), `python -B -m unittest discover -s tests -p test_mercado_livre_bridge.py -q` (60 aprovados), verificações de sintaxe, `git diff --check` e build de produção.

API publicada seletivamente em `/var/www/mdv-api`; PM2 `mdv-api` reiniciou e ficou online. `/status` respondeu HTTP 200 com MySQL OK. Gates de publicação, preço e estoque confirmados desligados pelo deploy. O diagnóstico publicado expôs que a rota exige associação de anúncio no catálogo do Mercado do Vale; essa associação não existia para os cruzamentos do ERP e a leitura foi bloqueada antes de consultar preços. A correção por SKU foi separada para a release `v1.2.730`. Release do site: pendente.
