# v1.2.60-totem-pix-foreground-recovery

Data: 2026-07-06

Release VPS: `/var/www/mdv-site/releases/20260706-175457-totem-pix-foreground-recovery`

## Resumo

Faz o Totem Pix voltar para frente quando outro aplicativo estiver aberto e houver Pix ativo.

## Ajustes

- Android atualizado para `versionName 1.20` / `versionCode 120`.
- Monitor nativo tenta mover a propria task do Totem para frente com `ActivityManager.AppTask.moveToFront()`.
- Ao detectar Pix ativo, o monitor publica notificacao dedicada de alta prioridade com acao direta para abrir o QR Code.
- O app solicita permissao `POST_NOTIFICATIONS` em Android 13+.
- O monitor declara `REORDER_TASKS` e reduz a nova tentativa de foco para 10 segundos durante Pix ativo.
- O display visual passa a mostrar `V1.20`.

## Observacao Android

Android moderno pode bloquear abertura automatica de Activity a partir de background. Esta release reforca o retorno ao Totem por task propria, retry curto e notificacao de alta prioridade. Para bloqueio absoluto de outros apps, o caminho definitivo continua sendo configurar o aparelho em modo dedicado/kiosk com lock task/device owner.
