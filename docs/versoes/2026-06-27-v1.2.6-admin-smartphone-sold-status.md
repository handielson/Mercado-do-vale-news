# v1.2.6-admin-smartphone-sold-status

Data: 2026-06-27

## Resumo

Corrige o badge do card admin para smartphones vendidos cujo IMEI esta registrado em `units`, mas nao em `products.specs`.

## Detalhes

- Smartphones ativos, rastreados e com estoque efetivo `0` aparecem como `Vendido`.
- Produtos comuns ativos, rastreados e com estoque `0` continuam como `Sem Estoque`.
- Mantem o status cadastral preservado para ativar/inativar.

## Validacao

- `node tmp-tests/admin-product-card-status.test.mjs`
- `npm.cmd run build`
