## Entrega

- A primeira resposta de uma conversa passa a usar a saudação correta de Petrolina, mesmo quando o cliente não cumprimenta, incluindo o primeiro nome somente quando confiável.
- Antes da lista, o atendimento usa uma introdução curta e gentil; os agentes receberam direcionamento para escrever com palavras próprias e evitar textos longos.
- A lista de celulares é ordenada e separada por marca, preservando a numeração contínua para escolha.
- Eventos antigos reproduzidos após reconexão são descartados antes de entrarem na fila do n8n.
- O Admin mostra um alerta global quando o n8n falha repetidamente.
- O Gestão MDV recebe push de queda e recuperação; a versão Android passa para `0.13.6` (`versionCode 63`).
- Um watchdog externo recupera a Evolution apenas para a assinatura confirmada de socket travado, com trava, cooldown e validação posterior.
- O título SEO incorreto do POCO C81 Pro foi corrigido diretamente na base de produção.
