# v1.2.46-totem-return-to-app-home

Data: 2026-07-05

## Resumo

Adiciona opcao para voltar para a tela inicial do app nas configuracoes do Totem Pix.

## Melhorias | implementacoes

- App Android atualizado para `versionName 1.13` e `versionCode 113`.
- Painel local do Totem Pix ganhou o botao `Voltar para tela inicial do app`.
- WebView passa a chamar a ponte nativa `returnToAppHome`.
- Ponte nativa Android traz a `MainActivity` para frente e recarrega `/display`.
- Manifesto publico passa a anunciar a versao Android `1.13`.
