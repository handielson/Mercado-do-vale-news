## Problema

Os campos de texto vindos da aba Shopee do modelo eram preenchidos no modal de sincronizacao, mas os campos de selecao continuavam em "Selecione...".

A causa era o formato do valor salvo: o editor do modelo salva selects usando o label exibido, como `3 Meses`, `Garantia do Fornecedor` e `Nao`, enquanto o modal da Shopee usa como `value` do option o `raw_name` retornado pela API, como `3 Months`, `Supplier Warranty` e `No`.

## Correcao

Foi criado `alignShopeeAttributeDefaultsToOptions` para normalizar os defaults antes de aplicar no estado do modal. A funcao compara o valor salvo contra `label`, `raw_name`, `original_value_name` e `value_id`, e converte para o mesmo valor usado no `<option>`.
