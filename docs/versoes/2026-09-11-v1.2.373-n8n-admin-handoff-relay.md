# v1.2.373 — Handoff do bot pelo WhatsApp do administrador

- A mensagem ao cliente ficou mais leve, com emojis moderados.
- Quando o bot solicitar atendimento humano, a API cria um código curto e avisa todos os números administrativos ativos.
- O aviso sempre inclui as instruções `RESPONDER`, `LIBERAR` e `ENCERRAR`.
- `RESPONDER <codigo> <mensagem>` envia ao cliente e mantém a IA pausada.
- `LIBERAR <codigo>` devolve a conversa à IA; `ENCERRAR <codigo>` fecha o atendimento humano.
- Apenas números cadastrados em `Novo Bot > Números admin` podem executar comandos.
- Avisos repetidos do mesmo handoff são deduplicados e os tickets expiram em 24 horas.
