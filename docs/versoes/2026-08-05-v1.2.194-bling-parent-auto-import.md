Tag: `v1.2.194-bling-parent-auto-import`

## Correção

- ao localizar uma variação pelo SKU, o formulário procura o pai pelo `bling_parent_id`;
- se o pai ainda não existir no Mercado do Vale, ele é consultado e importado automaticamente do Bling;
- após a importação, os vínculos pendentes são reconciliados e o campo Produto Pai recebe o UUID local.

## Causa

- o pai estrutural existia no Bling, mas não havia sido importado para a tabela local de produtos;
- sem um UUID local, o formulário não podia preencher `products.parent_id`, mesmo recebendo corretamente o ID do pai do Bling.
