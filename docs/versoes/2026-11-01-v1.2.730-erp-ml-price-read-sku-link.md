# v1.2.730 — leitura de preço pelo SKU confirmado no ERP

Data: 01/11/2026. Status: API publicada; manifesto do site pendente. Branch de destino: `main`. Tag: `v1.2.730-erp-ml-price-read-sku-link`. Commit: `97f7dd18`.

A rota somente GET de preço passa a aceitar a associação SKU/família confirmada no ERP quando o Mercado do Vale ainda não tem um vínculo próprio do anúncio. A API valida a existência da família de produto no catálogo e compara seu SKU ao SKU retornado pelo Mercado Livre, além de verificar o vendedor conectado. A consulta não cria vínculo nem altera cadastro, preço, anúncio ou estoque no Mercado do Vale. Operações de escrita continuam exigindo vínculo MDV e gate/chave separados.

Validações locais: suíte completa Mercado Livre e contrato estático, regressão de leitura sem vínculo MDV e bloqueio de escrita, bridge ERP, verificações de sintaxe e build. API foi publicada seletivamente com todos os gates desligados; leitura autenticada retornou `sku_mismatch` porque o ML expõe o SKU em `attributes[].SELLER_SKU`. A correção está na release `v1.2.731`; nenhum dado externo foi alterado.
