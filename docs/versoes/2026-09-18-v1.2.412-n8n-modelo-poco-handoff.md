## Problema corrigido

No atendimento `+55 74 8809-7502`, a busca `Valor do m6pro` não foi reconhecida como modelo de smartphone. A consulta ficou inconclusiva, o bot ativou o handoff automático `bot-product-specialist` por duas horas e a mensagem seguinte `M7 pro` foi bloqueada antes do classificador. A execução terminou como sucesso, mas não chegou ao envio.

## Comportamento publicado

- modelos Poco das famílias M, X e C são reconhecidos sem exigir a palavra `Poco`;
- `m6pro` é tratado como busca de smartphone;
- quando o modelo não existe no estoque, o bot informa isso e envia a lista atual;
- essa situação não ativa handoff automático;
- se a lista já foi enviada, ela não é repetida;
- `M7 pro` encontra o Poco M7 Pró 5G e usa o cartão oficial com PIX e cartão em 12x;
- buscas de acessórios, como `capa para M7 pro`, continuam no fluxo de acessórios;
- handoffs iniciados por uma mensagem manual do atendente continuam bloqueando o bot normalmente.
