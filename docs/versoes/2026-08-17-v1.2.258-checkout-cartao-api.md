## Correção

- transfere a cobrança por cartão Mercado Pago do navegador para a API;
- aceita apenas o token temporário gerado pelo Brick e valida que o pedido pertence ao cliente autenticado;
- atualiza status e reserva de estoque no servidor, sem permitir PATCH administrativo pelo cliente;
- retorna ao checkout somente o resultado necessário da cobrança.

## Proteção regressiva

- `tmp-tests/checkout-card-payment-server-static.test.mjs` exige endpoint restrito, validação de dono do pedido, uso do token na API e tratamento de reserva para aprovação ou recusa.

## Validações

- `node tmp-tests/checkout-card-payment-server-static.test.mjs`
- `node --check vps_server.js`
- `npm.cmd run build`
- endpoint sem autenticação deve continuar recusando cobrança; não foi realizado pagamento real de teste.

## Publicação

- site VPS publicado para usar o endpoint seguro;
- API `mdv-api` reiniciada para processar o cartão no servidor.
