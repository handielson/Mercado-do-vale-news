# v1.2.901-medidas-fonte-unica

Data: 23/11/2026. Publicada (site + dados). API sem mudança de código.

## O que mudou
- Peso e medidas do produto têm uma fonte só: colunas `weight_kg`/`dimensions`, com as Especificações (`weight_kg`, `dimensions.*`) como espelho.
- `services/productMeasures.mjs` (`product-measures-single-source-v1`): na gravação vale o campo que a pessoa mexeu (Especificações ou seção de medidas). O modelo só preenche o que faltar; antes ele sobrescrevia o produto em toda gravação.
- `services/products.ts`: create e update usam o resolvedor e espelham nas Especificações.
- `scripts/backfill-product-measures.cjs`: alinhou 1585 produtos (177 mudaram a medida do frete). Regra: Especificação vence; o lado com o padrão 20×14×7 perde para o outro; kits SFKU3XK2/K5 ficam com a altura somada.

## Como testar
- `node tmp-tests/product-measures.test.cjs`
- Mudar a altura nas Especificações de um produto, salvar e cotar no Calcular Frete.

## Volta
- Dados: backup `/var/www/mdv-api/backups/product-measures-2026-11-23T14-21-31-932Z.json` (id, weight_kg, dimensions, specs antigos). Lista do que mudou em `backups/medidas-preview-*.csv`.
