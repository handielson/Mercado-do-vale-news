# v1.2.231 — Modelo e cor no cadastro de smartphone por foto

Data: 11/08/2026

## Entrega

- Associa automaticamente a leitura `POCO C85` ao modelo `Poco C85` já cadastrado, mesmo quando o modelo pertence à família Xiaomi no catálogo.
- Mantém a associação estrita para não confundir o aparelho com modelos homônimos de outras marcas ou variantes Pro.
- Traduz cores comuns da etiqueta para português do Brasil, como `Black` para `Preto` e `Purple` para `Roxo`.
- Vincula a cor identificada à entidade de cor do sistema por `matched_color_id`.
- Quando a cor não existe, exige que o usuário selecione uma cor, cadastre uma nova ou atualize a lista antes de finalizar.
- Reprocessa as pendências existentes para preencher modelo, cor e preços atuais quando houver correspondência segura.
- Impede que o smartphone seja disponibilizado para venda sem uma cor cadastrada e confirmada.
- Corrige o classificador de publicação para incluir módulos de servidor localizados em `services/` no deploy da API.

## Banco de dados

- A API adiciona de forma idempotente a coluna `smartphone_photo_intakes.matched_color_id` no primeiro acesso após a publicação.

- Testes do núcleo de leitura e tradução.
- Testes de associação segura de modelos e cores.
- Testes estáticos do servidor, navegação e atualização do catálogo de cores.
- Build de produção do site.
- Verificação sintática dos servidores e do módulo da API.
