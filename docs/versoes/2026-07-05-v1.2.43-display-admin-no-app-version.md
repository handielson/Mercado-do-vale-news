## Resumo

Remove o prefixo de versao do aplicativo Android dos cards de display no admin e formata o aviso de atualizacao do Totem Pix como lista de mudancas.

## Alteracoes

- Remove `V1.xx -` antes do nome dos displays em `/admin/settings/displays`.
- Mantem a versao visivel apenas internamente no aplicativo/tela do Totem Pix.
- Formata `update_message` com versao e lista de melhorias/implementacoes.
- Preserva quebras de linha no aviso de atualizacao mostrado no Totem Pix.
- Atualiza teste de pareamento para validar as configuracoes visuais no admin/tipos.

## Pareamento web

O pareamento via web continua ativo:

- rota publica `/display` segue sem `ProtectedRoute`;
- `pdvDisplayService.pairDisplay` segue chamando `/pdv/displays/pair`;
- proxy VPS segue liberando `POST /pdv/displays/pair` sem login admin para o app/display.
