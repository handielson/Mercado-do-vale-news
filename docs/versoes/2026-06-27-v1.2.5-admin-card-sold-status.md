# v1.2.5-admin-card-sold-status

Data: 2026-06-27

## Resumo

Corrige o badge do card de produtos no admin para mostrar `Vendido` quando um produto serializado continua cadastralmente ativo, mas o estoque efetivo ja esta zerado.

## Detalhes

- Adiciona regra visual centralizada para o status do card admin.
- Produto serializado ativo, rastreado e com estoque `0` aparece como `Vendido`.
- Produto comum ativo, rastreado e com estoque `0` aparece como `Sem Estoque`.
- O status cadastral continua preservado para o botao de ativar/inativar.
