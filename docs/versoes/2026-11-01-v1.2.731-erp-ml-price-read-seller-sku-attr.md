# v1.2.731 — leitura de preço pelo atributo SELLER_SKU

Data: 01/11/2026. Status: pendente de publicação. Branch de destino: `main`. Tag: `v1.2.731-erp-ml-price-read-seller-sku-attr`.

A leitura de preço considera `attributes[].SELLER_SKU`, que é o formato usado nos anúncios atuais do Mercado Livre. O SKU precisa corresponder a um produto na família informada pelo ERP e o anúncio precisa pertencer ao vendedor conectado. A rota continua somente GET; nenhuma associação, preço, anúncio ou estoque é escrito no Mercado do Vale.

Validações locais aprovadas: 107 testes da suíte Mercado Livre e contrato estático, 60 testes da bridge ERP, sintaxe dos módulos, git diff --check e build de produção. API e leitura real pendentes após deploy.
