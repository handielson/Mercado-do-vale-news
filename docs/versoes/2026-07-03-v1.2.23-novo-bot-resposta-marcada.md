## Mudancas

- Novo Bot n8n permite marcar uma mensagem recebida e responder manualmente na conversa.
- O envio manual usa o campo `quoted` da Evolution API quando existe `wa_message_id`, criando resposta citada no WhatsApp.
- A resposta manual pode pausar o fluxo do bot para o atendente assumir o atendimento.
- API grava estado de lembrete por inatividade e fechamento interno da conversa.
- Job de inatividade roda periodicamente, tenta retomar a venda e marca a conversa como finalizada se o cliente nao responder.
- Workflow n8n foi ajustado para salvar `messageId` tambem em mensagens de texto recebidas.
