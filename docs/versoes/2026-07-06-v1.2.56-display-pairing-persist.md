## Resumo

Corrige a perda indevida do pareamento do display quando havia erro transitorio na consulta de estado.

## Alteracoes

- O display agora apaga o token pareado somente quando a API retorna erro explicito de token revogado/invalido.
- Erros temporarios de proxy, rede ou URL contendo `token=` nao removem mais o pareamento salvo.
- O monitor nativo Android foi ajustado no codigo-fonte para consultar `https://api.xiaomipetrolina.com.br/pdv/display-state` diretamente. Essa parte exige novo AAB para chegar aos aparelhos.
