# v1.2.478 — Synology como destino principal do backup

O pacote é verificado na VPS e enviado ao Synology sem criar uma segunda cópia temporária do arquivo grande. Cada parte, manifesto e hash são confirmados no NAS antes de excluir o pacote da VPS. Se o envio falhar, o pacote local continua disponível para nova tentativa. A VPS conserva no máximo três pacotes completos de contingência; o Synology retém 30 dias, protegendo pelo menos três conjuntos recentes e só limpando após um envio confirmado.

O painel administrativo informa se a cópia da VPS ainda existe. A publicação da API é seletiva para evitar alterações fiscais não relacionadas.
