- o filtro oculta exclusivamente os aparelhos com status `completed` (`Disponível para venda`);
- mantém o agrupamento e o contador baseados nos aparelhos visíveis;
- muda `Produto já cadastrado` para `Produto encontrado`;
- explica que o produto já existe, mas o aparelho ainda precisa ser concluído para ficar disponível à venda.
