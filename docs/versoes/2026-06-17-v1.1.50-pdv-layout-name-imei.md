## Resumo

Publicacao visual do PDV para padronizar a exibicao de nomes de clientes e melhorar a leitura das unidades serializadas no seletor de IMEI/Serial.

- `VERSAO_ATUAL.md`
- `docs/versoes/2026-06-17-v1.1.50-pdv-layout-name-imei.md`

## Mudancas

- Nomes de clientes exibidos no PDV passam por capitalizacao visual em formato de titulo.
- Seletor de unidade serializada continua por radio, mas exibe cada unidade em uma unica linha.
- Linha de unidade serializada passa a mostrar `IMEI 1: valor | IMEI 2: valor | Serial: valor`.
- Fonte do seletor de unidade serializada foi ampliada para facilitar leitura.
- Dados salvos de cliente e payload de venda permanecem inalterados.
