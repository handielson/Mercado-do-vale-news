## O Que Entrou

- A mensagem copiada de categoria do catalogo agora divide os produtos por marca.
- Dentro de cada marca, os produtos sao ordenados do menor para o maior preco.
- O orçamento copiado pelo carrinho admin troca o cabecalho para `Orçamento`.
- O orçamento copiado passa a incluir o link de cada produto abaixo das informacoes do item.
- A busca admin de produtos por IMEI preserva as unidades serializadas encontradas pela VPS em `available_units`, evitando que o filtro local descarte o produto hidratado.
