# 2026-06-21 v1.1.82 — shopee-model-auto-attributes

## Resumo

Ao definir uma categoria Shopee no cadastro de modelos (aba Shopee do ModelModal), o sistema agora busca automaticamente os atributos da categoria e preenche sugestoes (marca local, modelo do nome, defaults do template de capa de celular). Antes, o operador tinha que digitar o JSON `{ "attribute_id": "valor" }` manualmente.

Tambem inclui o fix v1.1.81 (search_synced_products) que estava pendente de publish.

## Causa Raiz (v1.1.82)

O `ModelModal.tsx` (aba Shopee) so fazia `setShopeeCategoryId(catId)` e `setShopeeCategoryName(catName)` ao definir uma categoria — nao chamava a action `attributes` da Shopee nem gerava sugestoes de valores. O campo "Atributos Padrao" era um textarea JSON vazio.

A infraestrutura de backend e a logica de sugestao ja existiam em outros arquivos (ShopeePage.tsx, shopeeFieldTemplates.js) mas nao eram acessiveis ao ModelModal.

## Correcao

### Novo helper compartilhado
Criado `pages/admin/settings/shopeeAttributeResolver.js` com:
- `extractShopeeAttributeTree(data)` — extrai arvore de atributos da resposta bruta da Shopee.
- `normalizeShopeeAttributes(data)` — normaliza no formato `{ attribute_id, label, mandatory, input_kind, attribute_value_list }`.
- `buildShopeeAttributeDefaultsPayload(attributes, product, template?)` — monta `{ attr_id: valor }` com sugestoes + chaves vazias para obrigatorios sem sugestao.
- `summarizeShopeeAttributes(attributes, payload)` — conta total/obrigatorios/preenchidos.
- Reexporta `buildShopeeTemplateAttributeValues` e `resolveShopeeFieldTemplate` de `shopeeFieldTemplates.js`.
- Helper nao tocou `ShopeePage.tsx` (mantido intacto para minimizar risco de regressao).

### ModelModal.tsx
- Import do `shopeeAttributeResolver.js`.
- Novos estados: `shopeeAttributeFields`, `shopeeAttributesLoading`, `shopeeAttributesError`, `shopeeAttributesRequestRef`.
- Funcao `loadShopeeAttributes(categoryId)`: fetch `/api/shopee-catalog?action=attributes&category_id=<id>`, normaliza, gera sugestoes, preenche o JSON.
- `useEffect` reativo a `shopeeCategoryId` que dispara `loadShopeeAttributes` automaticamente (via copia de similar, input manual, ou carga inicial).
- Ref race condition: `shopeeAttributesRequestRef` descarta respostas de categorias antigas.
- Brand name derivado de `brands.find(b => b.id === brandId)?.name`.
- UI: spinner de carregamento, mensagem de erro, botao "Recarregar", badges coloridos (verde = preenchido, laranja = obrigatorio vazio, cinza = opcional).
