## Mudancas

- A rota `POST /pdv/displays` agora trata `ER_DUP_ENTRY` e retorna `409` com mensagem controlada quando o nome/slug do display ja existe.
- A rota `PATCH /pdv/displays/:id` aplica o mesmo tratamento para edicoes que colidam com outro display.
- A tela de Displays Android mostra uma mensagem clara para orientar o operador a usar outro nome.
