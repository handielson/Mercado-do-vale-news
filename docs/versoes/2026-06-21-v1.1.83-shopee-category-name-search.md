## Resumo

A categoria Shopee do cadastro de modelos agora pode ser escolhida pelo nome, logo abaixo da Categoria Padrao. O operador nao precisa descobrir o ID manualmente: a tela busca categorias oficiais da Shopee, mostra resultados pelo caminho/nome e salva o ID internamente para carregar os atributos.

## Comportamento publicado

- Campo "Categoria Shopee" adicionado na aba JSON / IA, abaixo de "Categoria Padrao".
- Busca por nome usa `/api/shopee-catalog?action=categories` e `searchShopeeCategories`.
- Ao selecionar um resultado, o ID da categoria e salvo em `shopee_category_id`, o nome/caminho em `shopee_category_name` e os atributos sao carregados pelo fluxo existente.
- A aba Shopee tambem deixa de depender do campo primario de ID manual e passa a oferecer busca por nome.

## Protecao contra regressao

- `tmp-tests/model-modal-shopee-category-name-search-static.test.mjs` garante que o modal:
  - usa helpers de busca de categorias Shopee;
  - carrega categorias via `action=categories`;
  - renderiza "Categoria Shopee";
  - salva o ID internamente ao selecionar categoria;
  - nao volta a exigir input manual primario de ID.
