## Correcao

- Reproduz o erro TikTok `12052901` na consulta do status de um produto cujo vinculo local ainda estava como `DRAFT`.
- Quando `return_draft_version=true` for recusado porque o item ja mudou de estado, consulta uma unica vez a versao atual sem esse sinalizador.
- Atualiza o vinculo local com o status retornado, evitando que o proxy devolva 502 para estados como `PENDING` ou `ACTIVATE`.
