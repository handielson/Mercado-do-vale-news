## Resumo

Corrige a sincronizacao Shopee para tratar `Condicao` somente pelo campo nativo `condition: "NEW"`.

## Causa

O log de `add_item` mostrou que a Shopee rejeita o envio duplicado de Condicao quando `condition: "NEW"` tambem acompanha `attribute_id: 100413` em `attribute_list`:

```text
classification.attribute_value_not_map
Attribute value is not linked to Condition. Please select a valid value.
```

Mesmo com `value_id: 2497`, a classificacao da Shopee nao aceita esse atributo como valor de Condition nesse fluxo.

## Mudancas

- Mantem `Condicao = Novo` preenchida na tela de sincronizacao.
- Mantem `condition: "NEW"` no payload nativo da Shopee.
- Omite o atributo `100413` de `attribute_list` em `add_item` e `update_item`.
- Atualiza a protecao estatica para impedir que `100413` volte a ser enviado como atributo comum.
