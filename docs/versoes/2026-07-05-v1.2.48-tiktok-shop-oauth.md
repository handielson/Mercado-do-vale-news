## Escopo

- Cria a tela admin `/admin/settings/tiktok-shop` para configurar App Key, App Secret, Service ID e Shop Cipher.
- Adiciona URL de autorizacao seller do TikTok Shop com `service_id` e `state` assinado pelo backend.
- Adiciona callback publico `/api/tiktok-shop/oauth/callback` para trocar `code` por `access_token` e `refresh_token`.
- Salva metadados TikTok em campos `tiktok_*` de `company_settings`.
- Mantem credenciais em arquivo local ignorado `.env.tiktok.local` quando usado no ambiente local.

## Riscos E Cuidados

- O OAuth valida `state` no backend antes de trocar o codigo por tokens.
- Segredos nao devem ser enviados no chat nem versionados.
- O campo `TIKTOK_SHOP_CIPHER` pode ficar vazio nesta primeira fase; sera necessario para chamadas de loja quando avancarmos para catalogo/pedidos.
