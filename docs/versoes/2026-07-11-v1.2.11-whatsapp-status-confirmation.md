## Correcao

O envio de produtos para o Status do WhatsApp agora so e registrado como enviado quando a Evolution devolve uma chave de mensagem valida para `status@broadcast`. Timeout ou resposta sem essa confirmacao ficam como falha e nao avancam a rotacao da campanha.

O tempo limite padrao passou de 30 para 90 segundos para acomodar a latencia observada na Evolution API 2.3.7 sem gerar falso sucesso.
