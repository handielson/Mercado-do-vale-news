# v1.2.96 - Modal TikTok abre o anuncio pai

Data: 27/07/2026

## Alteracoes

- Ao clicar no indicador TikTok de uma variacao, o modal usa o produto que realmente possui o vinculo.
- Variacoes de um anuncio agrupado abrem o produto pai em vez de oferecer outro rascunho para o filho.
- O texto do indicador explica quando a variacao pertence ao anuncio do produto pai.

## Caso validado

- SKU filho `CSRN11PP`, exibido com o status herdado do anuncio agrupado.
