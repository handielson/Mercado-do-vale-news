## O que entrou

- O comprovante Pix passa a usar uma unica fonte de dados no backend para PDV e Pix avulso.
- O valor do comprovante usa `amount` em centavos, corrigindo casos como R$ 1,00 aparecendo como R$ 100,00.
- O envio de comprovante pelo display usa rota autenticada pelo token do display, sem exigir chave administrativa.
- O proxy da VPS libera as rotas publicas do display para QR e WhatsApp do comprovante.
- O display troca o campo inline de telefone por modal com teclado numerico proprio e botao de confirmar.
- O Pix gerado direto no PDV passa a criar referencia amigavel `PDV-...` em vez de mostrar UUID tecnico.
- Pix avulso usa o texto informado pelo operador no campo de descricao como identificacao do comprovante quando preenchido.
