# v1.2.420 — TikTok Shop automático

Pedidos TikTok novos são conciliados pela API a cada minuto. A NF-e autorizada do Bling é enviada no endpoint oficial `POST /fulfillment/202502/invoice/upload`, em JSON/Base64. O sistema aguarda o estado `INVOICE_UPLOADED` antes de chamar a expedição. Eventos webhook não expedem pacotes diretamente. O primeiro processamento grava uma data de ativação para impedir que vendas antigas já impressas sejam reimpressas; pedidos anteriores podem ser inseridos explicitamente na fila.

Quando o pedido entra em `AWAITING_COLLECTION`, uma fila única guarda a etiqueta e o recibo de conferência. O Lenovo imprime a etiqueta na Zebra e o recibo 90x100 mm na Comprovante, com itens, SKU, quantidade e localização de estoque, usando os mesmos dispositivos configurados para Shopee. O diário local impede envio duplicado ao Windows após quedas ou falhas de confirmação. A instalação seletiva faz backup e preserva o código Shopee/ML já instalado.

Arquivos: `vps_server.js`, `vps_server.cjs`, `deploy-vps-server-only.cjs`, `services/tiktokShopFulfillmentService.cjs`, `services/tiktokShopFulfillmentAutomation.cjs`, `services/tiktokShopPrintServer.cjs`, `scripts/tiktok-shop-print-agent.cjs`, `scripts/install-tiktok-print-lenovo.ps1`, `scripts/shopee-auto-print.cjs`, `scripts/mercado-livre-print-core.cjs`, testes focados e artefatos de versão.

Validações: testes de NF-e, transição fiscal, idempotência de impressão e Mercado Livre; sintaxe Node; build Vite. Validação física final no Lenovo depende da instalação do pacote e de um pedido apto.
