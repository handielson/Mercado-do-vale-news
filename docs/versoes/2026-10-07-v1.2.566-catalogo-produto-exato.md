## Problema e comportamento

O card do Redmi Note 15 Pro 4G preto, SKU RN15P8256P, abria o titanio RN15P8256T. Os dois registros compartilham o slug redmi-note-15-pro-4g; o grupo filtrado do catalogo nao inclui todas as cores e nao consegue determinar a colisao. A API por slug retornava o titanio.

ModernProductCard agora navega pelo ID exato de currentProduct. A PDP ja busca por ID e restaura o endereco legivel com cor e memoria. Busca por ID sem resultado passa a falhar sem recorrer a busca aproximada. Fonte de dados: API VPS/MySQL; nenhuma alteracao de produtos, precos, estoque ou schema. API sem deploy/restart.
