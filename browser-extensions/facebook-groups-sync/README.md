# Extensão Mercado do Vale — grupos do Facebook

Esta extensão lê somente os links de grupos que estiverem visíveis na conta Facebook já conectada no Chrome. Ela não recebe nem armazena senha e não publica anúncios automaticamente.

## Instalação

1. Abra `chrome://extensions`.
2. Ative **Modo do desenvolvedor**.
3. Clique em **Carregar sem compactação**.
4. Selecione esta pasta `browser-extensions/facebook-groups-sync`.
5. Se a extensão já estava instalada, clique em **Recarregar** no cartão dela.
6. Volte ao painel do Mercado do Vale e clique em **Puxar da conta aberta**.

A extensão abrirá automaticamente **Todos os grupos**, carregará a lista progressivamente e voltará o resultado para o painel. No sistema você pode escolher **Somente grupos de vendas** e pesquisar por nome.

O Chrome exige essa instalação única porque sites não podem ler os dados de outra aba diretamente.
